# Tarang

Tarang is a static presentation page for an agentic AI marine intelligence platform.

Live site: https://aditya1kumbhar.github.io/Tarang/

## Preview locally

From the repository root, run:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000> in a browser. The site has no build step or runtime dependencies and can be deployed directly to any static host.
