## 1. System Overview

**ORCA (Marine EcOsystem Reasoning with Collaborative Agents)** is an enterprise-grade Agentic AI marine intelligence and decision-support platform designed for Indian artisanal and mechanized fishing communities, coastal law-enforcement authorities, and disaster management teams.

### Key Architectural Invariants
- **Deterministic Math & Zero Hallucination in Geometry & Safety:** Spatial math, geofence checks, safety scoring, and A* routing are computed by deterministic tools (`pyproj`, `shapely`, `numpy`, `networkx`), never generated by the LLM.
- **Hard-Coded Safety Circuit Breaker:** Hard-coded fail-safe locks non-overridable `RED_ALERT` advisory when wave height, wind shear, Kallakkadal swell, convective lightning (CAPE), or maritime border distance (<1.5 NM to IMBL) breaches calibrated safety thresholds.
- **Data Ingestion & Operational Provenance:** Open-Meteo = live weather and marine observations (wave height, swell period/dir, wind speed/gusts, tidal drift currents); NOAA CoastWatch ERDDAP = live daily satellite SST (Coral Reef Watch 5 km) + Chlorophyll-a (VIIRS 9 km near-real-time gap-filled) for Potential Fishing Zone (PFZ) discovery; bundled grid (`indian_ocean_grid.json`) = offline fallback snapshot only. Bundled GIS assets include 12 Indian landing centres (`harbours_india.json`), international maritime boundary lines (`imbl_lines.geojson`), and marine protected areas (`mpa_zones.geojson`).
- **Deterministic 0-100 Sea-Venture Safety Index:** Multi-factor additive safety scoring calibrated with differential vessel tolerances for small country crafts ($H_{\text{crit}} = 1.8\text{m}$) and mechanized trawlers ($H_{\text{crit}} = 2.8\text{m}$).
- **Dual-Persona Interface:**
  - **Fisher View:** Single-vessel tactical safety dial, PFZ hotspot bearings, safe routing waypoints, and localized Web Speech audio.
  - **District Authority Board:** Coast-wide surveillance across all 12 major Indian landing centres with state filtering and risk analytics.
- **Multilingual Support (10 Languages):** Real-time script detection and synthesis across English and 9 Indian regional languages (Tamil, Malayalam, Telugu, Kannada, Marathi, Gujarati, Odia, Bengali, Hindi).

## 2. Multi-Agent Architecture

```text
User Query (Voice or Indic Text)
  │
  ▼
PlannerAgent (Intent Parser, Vessel Classifier, Task Decomposer)
  │
  ├──► OceanAnalyticsAgent ────► ocean_pfz_tool.py (SST Gradient, Chl-a, 7-Day Persistence)
  ├──► WeatherHazardAgent ─────► weather_marine_tool.py (Wave, Wind, Swell, CAPE Lightning, 0-100 Index)
  ├──► GeospatialNavAgent ─────► geospatial_tool.py (PyProj Geodesics, Shapely IMBL/MPA, A* Router)
  └──► ProductivityAgent ──────► productivity_tool.py (Marine Heatwave, Hypoxia/HAB, Turbidity Diagnostics)
  │
  ▼
SafetyCircuitBreaker (Deterministic Guardrail Node)
  │
  ├── [CRITICAL HAZARD] ──► Lock RED_ALERT, Inject Statutory Advisory Header, Quarantine PFZs
  └── [NORMAL] ──────────► Pass Verified State & Evidence Ledger
  │
  ▼
SynthesisExplainabilityAgent (Native Indic Synthesis + Evidence Citations + GeoJSON Map Payload)
```

|---|---|---|---|

| **Q2** | *Is it safe to venture into the sea tomorrow morning?* | PlannerAgent -> WeatherHazardAgent (`get_weather_marine_report` checking vessel wave, wind, swell, and CAPE thresholds) + SafetyCircuitBreaker. | `test_sih_official_query_2_safety_venture_tomorrow` |
| **Q3** | *What are the tide, weather, and sea conditions near my fishing location?* | PlannerAgent -> WeatherHazardAgent (Open-Meteo marine and weather APIs querying wave height, swell period/dir, wind speed/gusts, tidal drift currents). | `test_sih_official_query_3_tide_weather_sea_conditions` |
| **Q4** | *Are there any lightning or cyclone alerts in my area?* | PlannerAgent -> WeatherHazardAgent (CAPE convective potential energy lightning assessment, cyclonic swell surge detection, and safety alert state). | `test_sih_official_query_4_lightning_or_cyclone_alerts` |
| **Q5** | *Which regions show high chlorophyll concentration and favourable sea surface temperature?* | PlannerAgent -> OceanAnalyticsAgent (Biophysical PFZ ranking evaluating optimal SST $25.5-29.2^\circ\text{C}$ and chlorophyll-a concentrations). | `test_sih_official_query_5_chlorophyll_and_sst_regions` |
| **Q6** | *What is the safest route for a fishing vessel considering weather and sea-state conditions?* | PlannerAgent -> GeospatialNavigationAgent (`compute_astar_route` wave-weighted A* pathfinder on 0.05° grid avoiding rough waters, land, and MPAs). | `test_sih_official_query_6_safest_vessel_route` |
| **Q7** | *Why has fish productivity declined in a particular coastal region?* | PlannerAgent -> ProductivityDiagnosticAgent (`diagnose_productivity_decline` diagnosing Marine Heatwave thermal stratification, HAB hypoxia, or turbidity). | `test_sih_official_query_7_productivity_decline` |
| **Q8** | *Which fishing zones should be avoided due to hazardous marine conditions or geofencing restrictions?* | PlannerAgent -> GeospatialNavigationAgent (`evaluate_geofence` against IMBL boundaries and MPA polygons) + WeatherHazardAgent hazardous sea quarantine. | `test_sih_official_query_8_hazardous_or_geofenced_zones` |

## 4. Production Deployment & API Specifications

### Production Environment Notes
- **Live Production URL:** `https://tarang-0v0t.onrender.com`
- **Mandatory Google Authentication Gate:** All sensitive operational endpoints require an HMAC-SHA256 signed `orca_session` cookie issued via Google Identity Services token verification or authorized officer sign-in.
- **Production API Documentation:** Disabled in production (`/docs` and `/redoc` return HTTP 404 JSON envelopes) to enforce API surface hygiene.
- **Definitive Rate Limiting:** 10 req/min on `/api/v1/chat`, 120 req/min on standard endpoints backed by WAL-mode shared storage with reverse-proxy IP spoofing protection.

### Deployed FastAPI Endpoints
```text
GET  /api/v1/health                  # System health check (200 OK)
GET  /api/v1/auth/config             # Google Identity Services client ID configuration
POST /api/v1/auth/google             # Google OAuth2 credential verification & session cookie issuance
GET  /api/v1/auth/me                 # Current authenticated user profile
POST /api/v1/auth/logout             # Invalidate and clear secure session cookie
POST /api/v1/chat                    # Multi-agent conversational copilot & evidence ledger
GET  /api/v1/harbours                # All 12 Indian landing centres metadata
GET  /api/v1/dashboard-summary       # Single-harbour telemetry, safety index, and PFZ overview
GET  /api/v1/district-board          # Coast-wide 12-harbour fleet surveillance table
GET  /api/v1/demo-scenario           # 8 canonical evaluation scenarios (safe, danger, cyclone, pfz, route, conditions, alerts, chlorophyll_sst)
GET  /api/v1/geofences/imbl          # Indo-Sri Lanka & Indo-Pak IMBL boundaries as GeoJSON
GET  /api/v1/geofences/mpa           # Marine Protected Area boundary polygons as GeoJSON
```

## 6. Quick Start (Local Development Only)

> [!NOTE]
> The quick start below is for local development only. Production is deployed at `https://tarang-0v0t.onrender.com` with Google Identity Services access control and disabled `/docs`.

### Backend Setup
```bash
# 1. Activate virtual environment
source .venv/bin/activate

# 2. Install dependencies
pip install -r backend/requirements.txt

# 3. Start FastAPI server in development mode
uvicorn backend.main:app --host 127.0.0.1 --port 8000 --reload
```
Local API documentation available at `http://localhost:8000/docs` in development only.

### Frontend Setup
```bash
cd frontend

# 1. Install dependencies
npm install

# 2. Start Vite development server
npm run dev
```
Open `http://localhost:5173` in your browser.
