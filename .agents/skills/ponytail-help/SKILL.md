# Ponytail Help: Quick Reference Card

Use this skill as an instant lookup card for Ponytail's rules, modes, and command workflows.

## Quick Command Reference

- `/ponytail`: Activates core minimalism principles and the Decision Ladder.
- `/ponytail-review`: Runs an anti-bloat diff review and produces a delete-list.
- `/ponytail-audit`: Scans the entire codebase for architectural bloat and YAGNI violations.
- `/ponytail-debt`: Catalogs and tracks `# ponytail: later` technical debt items.
- `/ponytail-gain`: Displays lines of code saved and complexity reduced.
- `/ponytail-help`: Displays this reference card.

## Intensity Modes

- `lite`: Gentle checks for obvious dead code or massive dependencies.
- `full`: Balanced senior engineering discipline (default).
- `ultra`: Aggressive pushback against any speculative complexity or premature abstraction.

## The 7-Rung Ladder

`YAGNI` $\rightarrow$ `Reuse` $\rightarrow$ `Standard Library` $\rightarrow$ `Native Platform` $\rightarrow$ `Installed Dependency` $\rightarrow$ `One Line` $\rightarrow$ `Minimum Viable Code`
