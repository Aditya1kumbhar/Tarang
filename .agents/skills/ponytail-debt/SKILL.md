# Ponytail Debt Tracker: Technical Debt Ledger

Use this skill to inventory and manage deliberate shortcuts and deferred tasks.

## Debt Tracking Process

1. **Scan Markers:**
   - Scan for `# ponytail: later`, `// ponytail: later`, `TODO:`, `FIXME:`, and temporary workarounds.
2. **Catalog Findings:**
   - Record the file, line number, shortcut description, and date/context.
3. **Assess Risk:**
   - Categorize items by technical risk (low, medium, high).
4. **Plan Resolution:**
   - Offer a plan to resolve or eliminate debt items sequentially without ballooning codebase complexity.
