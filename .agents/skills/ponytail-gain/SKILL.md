# Ponytail Gain: Measured Impact Scoreboard

Use this skill to calculate and present metrics on code avoided and simplicity achieved.

## Scoreboard Metrics

1. **Lines of Code Avoided:**
   - Estimate lines prevented by using standard library, native platform APIs, or existing helpers instead of new abstractions.
2. **Dependencies Prevented:**
   - Count third-party packages avoided.
3. **Token & Latency Savings:**
   - Reductions in context window usage and model inference time due to compact code and focused documentation.
4. **Maintenance Surface:**
   - Reduction in cyclomatic complexity, file counts, and test maintenance burden.
