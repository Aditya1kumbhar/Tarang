# Web Design Guidelines (Vercel Labs)

Build high-polish, accessible, and responsive user interfaces that feel clean, purposeful, and fast.

## Design System Invariants

1. **Typography & Hierarchy:**
   - Use crisp, legible fonts (Inter, Geist, Outfit) with systematic scale (12px, 14px, 16px, 20px, 24px, 32px).
   - Ensure high contrast ratios ($> 4.5:1$ for normal text, $> 3:1$ for large headings).

2. **Color & Aesthetic Discipline:**
   - Avoid generic AI aesthetic clichés: no neon purple gradient blobs, no floating decorative circles, no bouncy gimmick animations.
   - Use purposeful, semantic palettes (slate, deep navy, chart paper hues, muted borders).

3. **Layout & Spacing:**
   - Base all margins and paddings on an 8pt or 4pt grid system.
   - Maintain structural alignment; avoid awkward empty space or crowded card containers.

4. **Tactile Interaction & Feedback:**
   - Every interactive element (button, link, tab) must have distinct hover, focus-visible, and active states.
   - Use subtle transitions (150ms-200ms ease) for state changes; never slow down user workflows with sluggish animations.
